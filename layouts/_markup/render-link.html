{{- /* Link render hook. Its only job is external links: rel="noopener" so the opened page cannot reach back through window.opener, and target="_blank". "External" means a different host than the site's own, not merely "starts with http" — an absolute link to your own domain is not external and should not open in a new tab. Fragment, mailto and relative links fall through untouched. */ -}} {{- /* The new tab is now optional. It has always been unconditional here, so the default is true and an existing site is unaffected; a site that would rather external links stayed in the tab — which is the accessibility-friendlier default, since it leaves the back button working — sets it false. rel="noopener" is kept either way: it costs nothing and it is not what the flag is about. */ -}} {{- $u := urls.Parse .Destination -}} {{- $external := and $u.Host (ne $u.Host (urls.Parse site.BaseURL).Host) -}} {{- $newTab := (partialCached "init.html" .Page).article.externalLinkForceNewTab -}} {{ .Text }} {{- /* Nothing after , deliberately. Whitespace between inline elements collapses to a visible space, so a trailing newline here renders "[link](x)." as "link ." — a space before the full stop, in every sentence that ends on a link. */ -}}
