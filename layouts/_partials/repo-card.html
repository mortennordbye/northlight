{{- /* One fetch-and-render mechanism for every repository card. The per-forge shortcodes are thin wrappers over this. **This fetches at build time**, which is the one thing in the theme that does. Two consequences, both handled rather than hoped about: 1. `docs/SPEC.md` §1 says the theme must build with no network access. That still holds for every site that does not use one of these shortcodes — nothing is requested unless a page calls one. For a site that does, a failed fetch is **not** a build failure: the card degrades to a plain link to the repository, which is the useful part of it anyway. Building on a train produces a working page, not a red build. 2. Hugo caches remote responses, so a rebuild does not re-fetch and a forge's rate limit is not hit once per build. `hugo --gc` clears it. Nothing is fetched by the *reader*. The numbers are baked into the HTML at build time, so a card costs a visitor no third-party request at all — which is the whole reason this is a build-time fetch rather than a script. Takes a dict: url the human URL of the repository (required, and the degraded fallback) api the JSON endpoint to read (required) shape which response shape to read: "github", "gitea" or "huggingface" label the text to show when the fetch fails */ -}} {{- $url := .url -}} {{- $api := .api -}} {{- $shape := .shape -}} {{- $label := .label | default $url -}} {{- $name := $label -}} {{- $desc := "" -}} {{- $stars := "" -}} {{- $forks := "" -}} {{- $lang := "" -}} {{- $live := false -}} {{- /* The three-failure split — fetched, offline, missing — was learned here and now lives in _partials/fetch-remote.html, which carries the full decision record: why a 404 warns and a transport failure does not, and why both ids are suppressible. Every fetching template routes through it so the distinction cannot be reimplemented wrong. */ -}} {{- $res := (partial "fetch-remote.html" (dict "url" $api "who" "repo-card" "hint" "the repository may have been renamed, moved or deleted, or the forge may be rate-limiting. The card has fallen back to a plain link.")).res -}} {{- with $res -}} {{- with try (unmarshal .Content) -}} {{- with .Err -}} {{- warnf "repo-card: %q did not return usable JSON — %s" $api . -}} {{- else with .Value -}} {{- $live = true -}} {{- if eq $shape "github" -}} {{- $name = .full_name | default $label -}} {{- $desc = .description | default "" -}} {{- $stars = .stargazers_count -}} {{- $forks = .forks_count -}} {{- $lang = .language | default "" -}} {{- else if eq $shape "gitea" -}} {{- $name = .full_name | default $label -}} {{- $desc = .description | default "" -}} {{- $stars = .stars_count -}} {{- $forks = .forks_count -}} {{- $lang = .language | default "" -}} {{- else if eq $shape "huggingface" -}} {{- $name = .id | default $label -}} {{- $desc = .pipeline_tag | default "" -}} {{- $stars = .likes -}} {{- $forks = .downloads -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{ partialCached "icon.html" (.icon | default "link") (.icon | default "link") }} {{ $name }} {{- with $desc }}{{ . }}{{ end }} {{- if $live }} {{- with $lang }}{{ . }}{{ end }} {{- if ne $stars "" }}{{ i18n (cond (eq $shape "huggingface") "likeCount" "starCount") $stars }}{{ end }} {{- if ne $forks "" }}{{ i18n (cond (eq $shape "huggingface") "downloadCount" "forkCount") $forks }}{{ end }} {{- end }}
