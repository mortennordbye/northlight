A photograph behind text is the glare this theme exists to avoid, so it is built with the guards a photograph needs rather than as a free-for-all: - A scrim sits between the image and the text. It is a flat token colour at a fixed opacity, not a gradient, so the contrast it buys does not vary across the block. - The text colour is fixed to the light-on-dark pair in *both* colour modes, because the image does not change when the palette does. A block that inverted with the theme would be legible in one mode and not the other over the same photograph. - Without `home.backgroundImage` set it renders as the ordinary intro. No band, no empty grey box. The author still owns the image.
