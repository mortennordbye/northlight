## Questions and bugs

Open an [issue](https://github.com/mortennordbye/northlight/issues). There are two forms: one for
a bug, one for a feature request. A bug report is far easier to act on with the Hugo version, the
relevant `hugo.toml` section, and either a link to the built page or the markdown that produced
it.

## Before reporting a bug

Two checks resolve most reports:

1. Your Hugo version is extended and at least the `min_version` in `theme.toml`.
2. The problem also happens in `exampleSite/`. If it does not, it is likely site configuration
   or a local override rather than the theme.

## Security

Do not use issues for vulnerabilities. See [SECURITY.md](SECURITY.md).

## Response times

This is a personal open-source project maintained in spare time. Issues are read, but there is
no service-level commitment attached to them.
